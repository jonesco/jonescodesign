Flatbed for macOS

How can we help?

Flatbed is a lightweight personal issue tracker for moving work from an idea to done.

Getting started

  • Click the plus button to create an issue.
  • Add notes, checklist steps, and related links in the issue detail.
  • Move work through Exploring, Working, Reviewing, and Done.
  • Use search and status filters to find what you need.

Does Flatbed require an account?

No. Flatbed has no separate account or team setup. Your Mac and Apple account handle local storage and optional private iCloud sync.

How does iCloud sync work?

When iCloud is available, Flatbed syncs issues through your private iCloud database. Make sure you are signed into the same Apple account and iCloud Drive is enabled on each Mac. If iCloud is unavailable, Flatbed continues with local storage.

How do I back up my work?

Use File → Export Backup to save a JSON backup at a location you choose. Use File → Import Backup to restore a compatible Flatbed backup.

What macOS version is required?

Flatbed requires macOS 14 Sonoma or later.

Contact support

If you run into a problem, include your macOS version and a short description of what happened. Please do not email private issue content unless it is necessary to explain the problem.
